Agent Monitor v2 设计稿

覆盖六项功能：F1 精确跳转、F2 超时再次提醒、F3 设置窗口、F4 全局快捷键与面板键盘操作、F5 Claude Code Hooks 事件源、F6 Token 用量。 行为、数据来源、实现文件和验收标准见同目录的 SPEC.md。本文件只管长什么样；凡是带 NEW 的元素都是新增的，其余元素与现有面板（website/assets/panel.css）保持一致，不要改动。 1 CSS px = 1 pt，颜色是 macOS 26 系统色，实现时用对应的 SwiftUI 语义色（见 SPEC.md「视觉规格」）。

1. 面板（深浅色）2. 新增行状态细节3. 右键菜单 / 齿轮菜单 4. Token 用量浮层5. 通知与菜单栏6. 设置窗口（6 页）7. Hooks 安装确认8. 键盘映射

2. 新增行状态细节

元素规格SwiftUI 写法
超时时间文字 NEW11pt semibold，systemRed；前缀 11pt 闹钟图标，间距 3pt。文字仍是等待时长（「12 分钟」）Label { Text } icon: { Image(systemName: "alarm.fill") }，.foregroundStyle(.red)
分组标题超时计数 NEW紧跟「等你回复」，10pt semibold，systemRed，文字「· N 个已超时」。N = 0 时不显示在 sectionHeader 增加可选 trailing: Text?
键盘选中态 NEW底色同悬停（.fill.quaternary）+ 内描边 1.5pt，accentColor 70% 不透明度，圆角 12（continuous）.overlay(RoundedRectangle(cornerRadius: 12, style: .continuous).strokeBorder(Color.accentColor.opacity(0.7), lineWidth: 1.5))
用量标签 NEW放在第二行（agent · 目录）末尾，右对齐；10.5pt，等宽数字，secondary 色；左右内边距 5pt，圆角 5pt；悬停时底色 .fill.tertiary、文字变 primary，停留 0.4s 后弹出第 4 节的浮层第二行改成 HStack(alignment: .firstTextBaseline) { Text(sub); Spacer(minLength: 8); UsageChip }
用量标签内容已知上下文窗口：10pt 圆环 + 百分比（「38%」）。只知道上下文 token 数：「460k」。只有步数（Antigravity）：「86 步」。没有数据（dsh）：不显示环形用 Circle().trim(from:0,to:p).stroke(lineWidth:1.6) 叠在 25% 不透明度的底环上
用量标签颜色百分比 ≥ 80%，或无窗口时上下文 ≥ 800k：orange；≥ 95%，或 ≥ 1M：red；其余 secondary见 SPEC F6「阈值」
快捷键提示条 NEW放在「全部标为已读」按钮下方（没有该按钮时放在列表下方）；10pt，tertiary 色，键名 semibold secondary 色；项间距 10pt，居中，上边距 2pt。只在键盘选中态存在时显示，淡入淡出 0.15s放进 MenuView 的 VStack，跟在 SessionList 后面

7. Hooks 安装确认

在「集成」页点「安装」或「查看改动…」时，以 sheet 形式弹出。展示的是将要合并进 ~/.claude/settings.json 的完整片段（真实内容由代码生成，不要写死）。

安装 Claude Code Hooks

Agent Monitor 会在 ~/.claude/settings.json 的 hooks 中追加以下条目。已有的配置不会改动，写入前会自动备份。新开的 Claude Code 会话会使用新配置；已经打开的会话可能需要重启才能生效。写入后文件的键顺序和缩进可能变化，内容不变。

    "PermissionRequest": [{ "matcher": "*", "hooks": [{ … }] }],

    "StopFailure":       [{ "matcher": "*", "hooks": [{ … }] }],
    "SessionEnd":        [{ "matcher": "*", "hooks": [{ … }] }]
